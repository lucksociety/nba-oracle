About this build

Each click fetches the day's schedule and the injury report live from ESPN's public API through the NBA Oracle Cloudflare proxy (which strips market fields), then directly from ESPN if the proxy is unreachable, and only then falls back to a repository snapshot refreshed about every 30 minutes by GitHub Actions; the data-sources panel shows which source was actually used on every run, rebuilds opponent-adjusted team ratings with early-season Bayesian shrinkage toward regressed prior-season ratings, applies home court, rest/back-to-back/travel and scenario-weighted injury effects, and runs a seeded possession-by-possession Monte Carlo (shared pace, team shooting shocks with fat tails, game-state feedback, garbage time, late-game fouling, overtime) in a Web Worker.

Honesty notes: probabilities are provisional model estimates; no walk-forward backtest or calibration has been performed. There is no tracking, lineup-level or play-by-play data; player impact is a simple box-score estimate. See the README for exactly what is implemented, simplified, or missing.
